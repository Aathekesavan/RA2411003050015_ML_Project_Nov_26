Safety & Execution

Scope questions.

Does SentinelX perform intrusive penetration testing?

No. SentinelX strictly restricts its checks to passive, non-disruptive public telemetry. It never attempts exploit payloads, password brute-forcing, SQL injection tests, or denial-of-service stress testing.

Why must I confirm authorization before checking?

Security posture tools must be operated responsibly. Even though SentinelX checks are non-disruptive, requiring operator authorization ensures clear intent and compliance with security best practices.

How can I run the full verified live inspection?

Launch the standalone Python server in the REPLICA folder (python server.py). This enables live socket handshakes and response header inspection on localhost. If opened as a static page, public DNS is verified live via DoH with sample labels for CORS-restricted browser probes.
