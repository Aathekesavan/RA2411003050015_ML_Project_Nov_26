F1 · technology-fingerprint

Outdated server version announced

Medium Sample Finding Hours
Context
The response header advertises PHP 7.4.3. PHP 7.4 reached end-of-life status on 28 November 2022 and no longer receives official security patches.
Observed Evidence
X-Powered-By: PHP/7.4.3
Server: Apache/2.4.41 (Ubuntu)
Expected Baseline
Supported runtime (PHP 8.2+) with version disclosure disabled (expose_php = Off)
Remediation
Upgrade to an actively supported runtime and disable version announcement headers in server configuration (ServerTokens Prod and expose_php = Off).

F2 · cookie-flags

Missing cookie security attributes

Medium Sample Finding Minutes
Context
The session cookie lacks the Secure and HttpOnly flags. Unflagged session tokens can be leaked over plaintext HTTP or accessed via client-side script injection.
Observed Evidence
Set-Cookie: PHPSESSID=b48da1e2f3a4c5d6; path=/
Expected Baseline
Set-Cookie: PHPSESSID=...; path=/; Secure; HttpOnly; SameSite=Lax
Remediation
Configure session.cookie_secure = 1, session.cookie_httponly = 1, and session.cookie_samesite = "Lax" in php.ini or application middleware.

F3 · email-dmarc

Missing DMARC anti-spoofing policy

Low Sample Finding Minutes
Context
No DMARC policy is published in DNS at _dmarc.example.com. Receiving mail servers have no instructions on how to handle spoofed messages pretending to come from your domain.
Observed Evidence
DNS TXT _dmarc.example.com: (No record found)
Expected Baseline
v=DMARC1; p=none; rua=mailto:dmarc-reports@example.com
Remediation
Add a TXT record at _dmarc.example.com with monitoring mode enabled (p=none), inspect aggregate delivery reports, and graduate to enforcement (p=quarantine or p=reject).

F4 · transport-hsts

Enforce HSTS downgrade defense

Low Sample Finding Minutes
Context
The root endpoint does not serve the Strict-Transport-Security header. Browsers will not pin HTTPS connections and remain susceptible to SSL-stripping downgrade attacks.
Observed Evidence
Strict-Transport-Security: (Header absent in HTTPS response)
Expected Baseline
Strict-Transport-Security: max-age=31536000; includeSubDomains
Remediation
Add the HSTS response header in web server configuration (Nginx: add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;).

F5 · security-headers-csp

Deploy Content Security Policy (CSP)

Low Sample Finding Days
Context
No Content Security Policy header was detected. CSP prevents unauthorized scripts, frames, and resource loading to mitigate cross-site scripting (XSS).
Observed Evidence
Content-Security-Policy: (Header absent)
Expected Baseline
Content-Security-Policy-Report-Only: default-src 'self'; ...
Remediation
Deploy a report-only CSP to audit third-party script and resource dependencies, then transition to enforcement mode.

F6 · vulnerability-disclosure

Publish RFC 9116 security.txt policy

Info Sample Finding Minutes
Context
No security contact policy was found at /.well-known/security.txt. Security researchers have no established channel to privately report vulnerabilities.
Observed Evidence
GET /.well-known/security.txt -> 404 Not Found
Expected Baseline
Contact: mailto:security@example.com Expires: 2027-12-31T23:59:59.000Z
Remediation
Create /.well-known/security.txt conforming to RFC 9116 with designated security contact email, encryption key, and expiration date.

Methodology

Inspection Boundaries.

  • HTTPS and HTTP 301 redirection verification
  • TLS certificate validation, cipher suites, and CA authority
  • HTTP response security headers (HSTS, CSP, XFO, XCTO)
  • Public DNS email authentication records (SPF, DMARC, CAA)
  • Coordinated vulnerability disclosure (RFC 9116 security.txt)

Every SentinelX report concludes with this scope boundary: SentinelX inspects web infrastructure exclusively from the outside, exactly as a modern client or visitor encounters it. We do not authenticate, submit forms, or execute intrusive exploitation.

What is strictly excluded from checks:

  • No credential guessing, password brute-force, or authentication cracking
  • No exploit payloads, SQL injection, fuzzing, or remote code execution tests
  • No denial-of-service, traffic flooding, or resource exhaustion testing
  • No internal mail server infrastructure penetration or unauthorized relay abuse

Autonomous exterior posture verification with verifiable evidence and remediation.
